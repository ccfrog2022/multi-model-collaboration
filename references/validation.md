## 重现检查

在本目录的上一级（skill 根目录）运行：

```powershell
pwsh -NoProfile -File tests/Test-Package.ps1
python -B tests/test_platform_contracts.py
```

macOS 第二条命令使用 `python3`。第一条命令也可以通过 `-Python` 指定解释器绝对路径，通过 `-ScratchRoot` 指定新的验证目录。Windows 测试目录使用 NTFS。

## 运行时检查范围

所有调用记录任务、角色与 InstanceId。JSON 适配器额外返回实际会话 ID，并接受跨工具复用检查；原生 CLI 的实际会话独立性由接入验证和协调者核实，统一自动检查仍待补齐。具体规则见 [工具接入约定](tools.md)。

公开操作包含 `RecoverTask`、`Rework`、`Handoff` 与 `RecoverLock`，依次用于异常核验、同一任务的新修订、符合条件的调用交接和遗留锁恢复。`RecoverTask` 根据具体处理报告核验已记录进程退出、越界文件恢复、冻结测试与备份，再追加恢复记录并要求新修订。缺失进程身份或关键原始记录时先恢复现场和记录。具体状态衔接见 [交接说明](handoff.md)。

helper 明确未启动时记录 `not_started`；已启动后失联或启动结果未知时仍需补齐真实进程证据。当前进程核验对 PID 复用采用保守判断。历史控制文件继续逐次检查，扫描开销随记录数量增长。

## macOS 待完成项

当前平台实现包含文件 mode、uid/gid、ACL、xattrs、flags 和时间的采集与恢复，以及启动握手、进程组、实际创建身份和超时处理。

**多进程 CLI 的自动清理验收仍需完善。** 当前实现观察到 fork 事件时，将 `cleanup` 记录为 `uncertain`，任务进入待处理状态。普通 CLI 派生子进程也会触发这一行为，因此这一部分需要继续实现与验证。

后续实机验证重点：

1. 在 Apple Silicon 与 Intel 环境检查平台调用和 Python / PowerShell 配合。
2. 在 APFS 大小写敏感与不敏感卷检查路径、中文文件名和同名大小写文件。
3. 对带有自定义权限、ACL 和 xattrs 的已有文件执行接入、备份与回滚，比较原件字节及元数据。
4. 检查正常子进程、快速双重 fork、进程脱离、超时和协调进程退出时的清理。
5. 使用实际工具完成普通与重要任务，并记录角色权限、会话身份与证据。

## 实现依据

macOS 的文件属性和进程身份字段参考 Apple 的 [文件属性接口](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/setattrlist.2.html) 与 [proc_info.h](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/proc_info.h)。进程事件限制参考 [event.h](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/event.h)；其中 `NOTE_TRACK`、`NOTE_TRACKERR` 和 `NOTE_CHILD` 已标记为不支持。Python 进程调用采用标准库 [subprocess](https://docs.python.org/3/library/subprocess.html)。
